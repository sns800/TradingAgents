## 1. 계약 우선 원칙과 스키마

**목적** 수집기·저장소·API·프론트 4개 층이 **구현 전에** 같은 키·필드·열거값에 합의하고, 그 합의를
코드로 강제한다. 합의 문서는 [CONTRACT.md](CONTRACT.md), 코드 표현은 `schema.py`다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `schema.py:Observation` | 관측치 1건 (CONTRACT 3장과 필드 1:1) |
| `schema.py:Observation.__post_init__` | 생성 시점 형식 검증 |
| `schema.py:Observation.pk` / `.sk` | DynamoDB 키 생성의 유일한 지점(`OBS#<indicator>#<iso>` / `<freq>#<period>`) |
| `schema.py:Observation.to_item` / `.to_json` | 저장용(Decimal) / API·덤프용(float) 직렬화 |
| `schema.py:Doc` · `Doc.__post_init__` | 정성 문서 + AI 산출물 규칙 강제 |
| `schema.py:validate_period` | freq별 period 정규식 검증 |
| `schema.py:to_decimal` · `_decimalize` · `undecimalize` | float ↔ Decimal 경계 변환 |
| `schema.py:now_iso` · `today_str` | UTC 타임스탬프(초 정밀도)·날짜 |

**알고리즘·규칙**

1. **생성 즉시 검증** — `Observation.__post_init__`가 ① `validate_period(freq, period)`
   (`D/W/E`=`YYYY-MM-DD`, `M`=`YYYY-MM`, `Q`=`YYYY-Qn`, `Y`=`YYYY`) ② `iso`를 대문자로 정규화
   ③ `flags`가 `FLAGS` 7종 열거값인지 ④ `value`와 `payload` 중 **최소 하나**가 있는지 확인한다.
   잘못된 관측치는 저장까지 가지 못하고 생성 시점에 `ValueError`가 된다.
2. **Decimal 경계는 단 한 곳** — DynamoDB는 float를 거부하므로 `to_item()`이 `value`를
   `to_decimal`(소수 6자리 반올림)로, `payload`를 `_decimalize`로 재귀 변환한다. 읽기 경로는
   `store.py`가 `undecimalize`로 되돌려 JSON 친화 dict만 밖으로 낸다.
3. **AI 문서 규칙** — `Doc.__post_init__`는 `ai_generated=True`인데 `quotes`가 비면 거부하고,
   `ai_generated`이면서 `review_status="approved"`인데 `reviewed_by`가 없으면 **`pending`으로 강제**한다
   (사용자 결정 4: 노출하되 배지·검토 상태를 붙인다).
4. **복합값 관측** — `elec_mix`·`exports_top_hs2`·`top_companies`·`cb_stance`는 `value=None` +
   `payload`로 저장한다. `to_item()`은 `payload`가 없으면 키 자체를 빼서 빈 속성을 만들지 않는다.

**엣지 케이스·특례**

- 주간(`W`)·이벤트(`E`) 빈도의 period는 **날짜 형식**이다(주는 조사 종료일, 이벤트는 선거일).
- `flags`는 리스트라 `Observation` 객체가 병합 단계에서 공유되면 플래그가 누적될 수 있다 —
  `collect.py`의 병합은 `if "fallback_source" not in o.flags` 가드를 항상 거친다.

**관련 테스트**

- `tests/test_macro_store.py::test_fake_table_rejects_float_like_dynamodb` — float 유입 탐지
- `tests/test_macro_store.py::test_payload_observation_revision_keeps_payload` — 복합값 개정 이력
- `tests/test_macro_registry.py::test_모든_지표의_열거값이_CONTRACT_2장_범위다`

**알려진 한계** 검증은 **형식**만 본다. "단위가 지표 정의와 맞는가", "값이 현실적인가"는
레지스트리 검증(2장)과 각 소스 모듈의 몫이다. `jsonschema` 패키지는 쓰지 않는다(워커 이미지 의존성 최소화).

## 2. 레지스트리

**목적** 국가 20개와 지표 38개의 단위·빈도·집계 규칙·소스 우선순위를 YAML 한 곳(`registry.yaml`)에
두고, 로드 시 계약 위반을 **한 번에** 보고한다. 국가 목록·소스 코드·시리즈 문자열을 다른 모듈에
하드코딩하지 않는다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `registry.py:load_registry` · `default_registry_path` | YAML 로드 후 `validate` 실행 |
| `registry.py:_country_from_dict` · `_indicator_from_dict` | dict → dataclass (알 수 없는 키를 오류로) |
| `registry.py:validate` · `_validate_countries` · `_validate_indicators` | 위반을 모아 `ValueError` 1회 |
| `registry.py:Country.code` · `Country.yahoo_fx` · `Country.in_group` | 소스별 코드 조회 |
| `registry.py:Indicator.sorted_sources` · `.source_names` · `.source_entries` | 소스 우선순위(priority 오름차순) |
| `registry.py:Indicator.is_composite` · `.is_derived` | 복합값·파생 지표 판정 |
| `registry.py:Registry.countries_for_source` | 소스가 **실제 담당하는** 국가 목록 |
| `registry.py:Registry._is_native_euro_provider` · `_entry_matches_country` · `_entry_covers` | 유로·`only` 규칙 판정 |
| `registry.py:Registry.to_meta_items` | `SERIES#<indicator>/META` + `SERIES#__countries__/META` 항목 생성 |
| `registry.py:is_euro_shared` | 유로 공통 지표(`policy_rate`·`m2_*`·`fx_*`) 판정 |

**알고리즘·규칙** (`_validate_*`가 검사하는 항목)

1. 국가 수는 **정확히 20**, `iso` 중복 없음·2자리, `iso3`·`name_ko`·`ccy`·`groups` 필수, `euro`는 bool.
2. `codes` 키는 `CODE_KEYS`(`bis` `oecd` `wb` `imf` `yahoo_fx` `fred_fx` `ember` `owid`)만 허용하고
   그중 `bis`·`oecd`·`wb`·`imf`는 **필수**. `yahoo_fx`는 `{symbol, invert}` 또는 `null`.
3. 지표 id 목록은 `INDICATOR_IDS`와 **순서까지** 같아야 한다(누락·초과를 각각 표기).
4. `unit`∈`UNITS`, `category`∈`CATEGORIES`, `native_freq`∈`FREQS`, `agg`∈`AGGS`,
   `decimals`는 0~6 정수, `higher_is`는 `neutral`만(지표마다 "높으면 좋다"를 화면이 단정하지 않기 위함).
5. `store_freqs`는 비어 있을 수 없고 `native_freq`를 포함해야 하며, `native_freq`보다 **고빈도를 넣을 수 없다**
   (`FREQ_RANK` 비교).
6. `yoy_from`·`derived_from`이 가리키는 지표는 반드시 존재해야 한다.
7. 위반은 즉시 예외를 던지지 않고 리스트에 모아 마지막에 `ValueError` 한 번으로 보고한다 —
   YAML 한 번 수정에 여러 오류를 함께 고칠 수 있다.

**유로 규칙** `Registry.countries_for_source(name, indicator_id)`는
① 지표가 유로 공통이면 회원국(DE·FR·IT)을 빼고 EU만 남기며, ② 소스가 유로존 집계 코드를 자체
제공하는 경우(`_is_native_euro_provider`, 예: OECD `EA`, World Bank `EMU`, Ember `EU`)는 EU를 대상에 넣고,
③ `only`/`except` 항목(`_entry_matches_country`)과 소스 코드 자리표시자가 없는 국가를 제외한다.
`collect.py:Collector._countries_for`가 지표별 결과의 **합집합**을 취해 소스 실행 대상을 만든다.

**엣지 케이스·특례**

- 레지스트리에 등록된 지표가 없는 정성 소스(`energy_policy` 등)는 `_countries_for`가 선택 국가 전부를
  넘기고 모듈이 자체 판단한다.
- `coverage_note`는 검증 대상이 아닌 **사람이 읽는 메모**다(소스 실측 결과 기록용).

**관련 테스트**

- `tests/test_macro_registry.py::test_지표는_38개이고_CONTRACT_고정_목록과_순서까지_같다`
- `tests/test_macro_registry.py::test_소스별_수집_국가에_유로_참조_규칙이_반영된다`
- `tests/test_macro_registry.py::test_소스_코드_자리표시자가_없는_국가는_제외된다`
- `tests/test_macro_registry.py::test_to_meta_items는_CONTRACT_4장_키를_만든다`
- `tests/test_macro_registry.py::test_국가_수_불일치와_열거값_위반도_잡는다`

**알려진 한계** `coverage_note`는 자동 동기화되지 않는다 — 소스 커버리지가 바뀌면 사람이 갱신해야 한다.
`priority`는 정수 수동 관리이므로 소스를 추가할 때 기존 값을 확인해야 한다.

## 3. 수집기 오케스트레이션

**목적** 소스 모듈은 "수집만" 하게 두고, **실행 순서·케이던스·실패 격리·우선순위·파생·저장·기록**을
`collect.py` 한 파일에 모은다. Fargate 진입점이기도 하다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `collect.py:Options` · `parse_args` · `options_from_args` · `main` | CLI 계약 |
| `collect.py:build_store` | 운영(boto3) / dry-run(`FakeTable`·`FakeS3`) 저장소 구성 |
| `collect.py:Collector.run` | 락 획득 → `_run_locked` → `finally` 락 해제 |
| `collect.py:Collector._run_locked` | 10단계 실행 순서의 본체 |
| `collect.py:Collector._stage` | 후처리 단계 1개를 격리 실행(실패는 `post_errors`) |
| `collect.py:Collector._run_source` | 소스 1개 실행 + 상태(`ok`/`partial`/`failed`/`skipped`) 판정 |
| `collect.py:Collector._cadence_check` | `INGEST#<source>/LATEST.next_due` 도래 판정 |
| `collect.py:Collector._resolve_since` | `--since` 없을 때 증분 시작일 결정 |
| `collect.py:Collector._selected_sources` · `_selected_isos` · `_countries_for` | 대상 선택·검증 |
| `collect.py:Collector._prepare_llm` · `_llm_budget` · `_seen_cb_urls` | LLM 핸들·예산·변경 감지 힌트 |
| `collect.py:Collector._catalog_loader` · `_fx_rates` | `companies` 소스 주입값 |
| `collect.py:Collector._log_ingest` · `_summary` | INGEST 기록·종료 요약 |
| `collect.py:dump_state` · `load_state` | 테이블·S3 전체를 JSON 1개로 덤프/복원 |
| `sources/base.py:CollectContext` | 소스가 쓰는 유일한 창구(HTTP·원본 저장·오류 기록·since·llm) |
| `sources/base.py:_build_session` · `retry_call` | 세션 재시도·개별 호출 재시도 |

**알고리즘·규칙 — 실행 순서** (`_run_locked`)

1. `store.put_meta_items(registry.to_meta_items())` — 지표 사전은 **매 실행** 갱신.
2. 락 획득 실패 시 어떤 소스도 실행하지 않고 **exit 0**(경고 로그만).
3. `CollectContext` 구성 → `_prepare_llm`(LLM·`seen_urls`·`seen_hashes`) → `catalog_loader` 주입.
4. 소스 루프: `QUANT_ORDER`(yahoo → bis → oecd → imf → fred → ember → owid → worldbank → wits →
   companies) → `LLM_ORDER`(cb_statements → wiki_polls → energy_policy). `SOURCE_MODULES` dict를
   테스트가 가짜 모듈로 교체한다.
5. `_stage("merge_put", …)` → `_stage("derive", …)` → `_stage("poll_of_polls", …)` →
   `_stage("rebuild", …)` → `_stage("weekly_brief", …)` → `_stage("log_ingest", …)`.
6. `--dump` 지정 시 상태 덤프 → `_summary` 표 출력 → 종료 코드 계산.

**알고리즘·규칙 — 케이던스**

1. `--force`면 항상 실행. INGEST 기록이 없으면 "첫 실행"으로 실행.
2. `next_due`는 **날짜 경계**다 — `store.py:_next_due`가 `(finished_at의 날짜 + cadence_days)의 00:00 UTC`를
   만든다. 매일 21:00 UTC 고정 기동에서 시각 기준으로 비교하면 daily 소스가 **격일로 밀리는** 문제가 있었다.
3. `status`가 `failed`/`partial`이면 `cadence_days`와 무관하게 `next_due`를 다음 날 00:00 UTC로 앞당기고
   `retry_reason`을 남긴다(`store.py:RETRY_STATUSES`, `RETRY_DAYS=1`).
4. `CADENCE_DAYS` = daily 1 · weekly 7 · monthly 30 · quarterly 90. 값의 출처는 모듈의 `CADENCE` 상수다.

**알고리즘·규칙 — 실패 격리와 종료 코드** (`_run_source`)

1. 소스 모듈이 예외를 올리면 `status="failed"`로 기록하고 **다음 소스로 진행**한다.
2. 예외 없이 오류만 기록됐고 산출물이 0이면 `failed`, 산출물이 있으면 `partial`, 오류가 없으면 `ok`.
3. 국가 단위 실패는 각 소스 모듈이 `ctx.record_error(source, iso, msg)`로 남기고
   `SourceRun.failed_isos()`가 INGEST의 `countries_failed`를 만든다.
4. 종료 코드: **실행한 소스가 전부 `failed`면 1**, 아니면 0(부분 실패는 INGEST `status=partial`로만 표현).

**알고리즘·규칙 — 락·증분·네트워크**

- 락: `store.acquire_lock(run_ts)`가 `CONFIG / LOCK#collect`에 조건부 put
  (`attribute_not_exists(pk) OR expires_at < now`), TTL 3시간. `finally`에서 `release_lock`은
  **holder 일치 조건**으로 자기 락만 지운다. 태스크가 죽어 남은 락은 TTL 후 다음 기동이 넘겨받는다.
- 증분: `--since` 없으면 선택 소스들의 `INGEST.finished_at` 중 **가장 오래된 값 − 45일**
  (`INCREMENTAL_LOOKBACK_DAYS`)을 쓰고, 기록이 없는 소스가 하나라도 있으면 `None`(소스 기본 시작일 = 전체).
- 네트워크: `_build_session`이 `Retry(total=2, backoff_factor=1, status_forcelist=429/5xx)`를 붙이고
  `ctx.get()`이 `DEFAULT_TIMEOUT=30`초를 기본 적용한다. `retry_call`은 개별 호출용 2회 재시도.
  yfinance는 내부 타임아웃이 없어 진입점에서 `socket.setdefaulttimeout`을 건다.

**엣지 케이스·특례**

- `_selected_sources`는 알 수 없는 소스·국가 코드를 `ValueError`로 거부하고 CLI는 **종료 코드 2**를 낸다.
- `_llm_budget`은 **CONFIG#MACRO 우선**, env `MACRO_LLM_DAILY_TOKEN_BUDGET`는 CONFIG 항목이 없을 때만
  초기값으로 쓴다(운영자가 조정한 예산을 다음 기동이 되돌리는 문제 방지).
- `_ProbeSet`은 `seen_hashes` 조회를 기록하는 하위호환 장치다 — 모듈이
  `ctx.extra["energy_hashes"]`를 직접 남기는 현재 구현에서는 쓰이지 않는다.
- dry-run은 `FakeTable`/`FakeS3`를 쓰고 원본을 로컬 `./.macro_raw/`에만 떨어뜨린다(AWS 쓰기 없음).

## 4. 병합과 폴백

**목적** 같은 (지표, 국가)에 여러 소스가 값을 낼 때 **무엇을 채택하고 무엇을 버리는지**, 그리고
"대체 소스로 채웠다"는 사실을 어떻게 남기는지를 한 함수에 모은다. 소스 모듈은 우선순위를 판단하지 않는다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `collect.py:merge_observations` | 우선순위 병합 (순수 함수) |
| `collect.py:_module_order` | 관측을 낸 모듈을 `Indicator.source_names()` 순서로 정렬 |
| `collect.py:_has_missing_higher_source` | `fallback_source` 플래그 부착 여부 판정 |
| `collect.py:_is_euro_member_shared` | 유로 회원국 공유 지표 폐기 판정 |
| `collect.py:fill_fx_month_from_daily` | 환율 D→M 기말 폴백 (순수 함수) |
| `collect.py:synth_us_fx_monthly` | 미국 `fx_usd` 월별 1.0 합성 (순수 함수) |
| `collect.py:Collector._merge_and_put` · `_fill_fx_monthly_fallback` · `_synthesize_us_fx` | 위 함수들의 호출·저장 |
| `collect.py:Collector._prune_annual_fallbacks` · `_has_finer_path` | 연간 최후 폴백 정리 |
| `collect.py:Collector._put_docs` | 문서 저장(소스별 집계) |

**알고리즘·규칙** (`merge_observations`, (지표, 국가) 단위)

1. 유로 회원국의 공유 지표(`EURO_SHARED_INDICATORS`)는 소스가 내더라도 **버린다**(API가 EU 값을 복제).
2. `primary` = `sorted_sources()` 순서로 **가장 앞선, 관측을 낸 소스**. 그 소스의 관측은 전부 채택.
3. 하위 소스는 primary의 **가장 고빈도보다 더 고빈도인 것만** 보충 채택한다
   (예: BIS `fx_usd` M이 있어도 yahoo D는 유지). 같은/더 낮은 빈도는 primary(또는 그 저빈도 집계)가 덮으므로 버린다.
4. primary보다 우선순위가 높은 소스가 **이번 실행에 참여했고**(`ran_sources`) 그 국가를 담당하는데
   값을 못 냈으면, 채택된 관측 전부에 `fallback_source`를 붙인다. 참여하지 않은 소스
   (`--sources yahoo`처럼 범위를 좁힌 실행)는 판단 근거가 없어 플래그를 붙이지 않는다.
5. 반환은 `{모듈명: 채택 관측}`이다 — 소스별로 `put_observations`를 나눠 호출해 INGEST의
   `n_new`/`n_updated`를 소스 단위로 남기기 위함이다.

**특례 1 — 환율 월별 폴백** `fill_fx_month_from_daily`는 `aggregate.to_lower_freq(daily, "M", "last")`로
월 기말값을 만들고 `fallback_source` 플래그와 method 사족("BIS 월별 부재로 yahoo 일별을 기말 집계한 폴백")을
붙인다. OBS 키가 같아(`OBS#fx_usd#<iso>` / `M#YYYY-MM`) 소스가 달라도 같은 자리를 채운다.
`_fill_fx_monthly_fallback`은 **BIS가 그 국가의 월별을 이미 냈으면 실행하지 않는다**.

**특례 2 — 미국 환율 기준값** 어떤 소스도 US `fx_usd`를 내지 않는다(정의상 1.0). `synth_us_fx_monthly`가
이번 실행의 **다른 국가** 월별 관측의 최소~최대 월 범위를 `aggregate.periods_between`으로 채워
`value=1.0`, `source=derived`, `series_id=USD_BASE`, `flags=["derived"]`로 합성한다. 중간 달을 빼먹으면
`fx_value_index`와 저빈도 집계에 구멍이 생기므로 **모든 월을 채운다**. 일별은 만들지 않는다.

**특례 3 — 연간 최후 폴백 정리** `_prune_annual_fallbacks`는 `*_yoy` 지표의 연간 폴백
(예: World Bank 연간 `cpi_yoy`)을 보고, `_has_finer_path`가 ① 더 고빈도의 직접 관측이 있거나
② `yoy_from` 원천 시계열이 있어 파생이 가능하다고 판정하면 **버리고**, 아니면 채택하되 `fallback_source`를 붙인다.

**엣지 케이스·특례**

- 레지스트리에 없는 모듈이 관측을 내면 `_module_order`가 뒤로 붙인다(테스트의 가짜 모듈).
- 어떤 소스도 값을 주지 못한 (지표, 국가)는 `LATEST#<indicator>`에 항목을 만들지 않고 프론트가 '—'로 표시한다.

## 5. 파생과 저빈도 집계

**목적** 원천이 주지 않는 시계열(전년비·통화가치 지수)을 계산하고, `store_freqs`에 선언된 저빈도(M/Q/Y)를
만든다. 계산은 전부 순수 함수(`aggregate.py`), 대상 선택·저장은 `collect.py`가 한다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `aggregate.py:to_lower_freq` | D→M / M→Q / Q→Y 집계 (`last`·`mean`·`sum`) |
| `aggregate.py:yoy` · `DEFAULT_YOY_LAG` | 같은 빈도 12개월/4분기/1년 전 대비 |
| `aggregate.py:index100` · `_resolve_base` · `_base_note` | 기준 기간 100 지수화 |
| `aggregate.py:fx_value_index` | 기준환율 ÷ 환율 × 100 |
| `aggregate.py:fuel_dependency` | `max(0, 1 − 생산/소비) × 100` |
| `aggregate.py:bucket_of` · `period_end_date` · `periods_between` · `previous_period` · `period_sort_key` | 기간 계산 |
| `aggregate.py:_agg_method` · `_require_homogeneous` | 한국어 method 문구·입력 동질성 검사 |
| `collect.py:Collector._derive` · `_derive_yoy` · `_derive_fx_value_index` | 파생 지표 생성 |
| `collect.py:Collector._aggregate_low_freq` · `_bucket_start` | 저빈도 집계 |
| `collect.py:Collector._series_with_run` · `_run_obs` · `_has_direct` | 저장값 + 이번 실행값 합성 시계열 |
| `collect.py:Collector._incremental` · `_window_start` · `_touched_isos` | 증분 실행의 창·대상 축소 |
| `collect.py:fx_value_index_yearly` | 월별 환율 → 통화가치 지수(순수 함수) |

**알고리즘·규칙**

1. **파생 대상 선택** — `_derive`는 `Indicator.is_derived`인 지표만 돈다. `yoy_from`이 있으면
   `_derive_yoy`, `derived_from == "fx_usd"`면 `_derive_fx_value_index`. `fuel_dep_*`처럼
   `derived via <source>`인 지표는 소스 모듈이 이미 만들어 두므로 건드리지 않는다. 지표 단위로
   try/except를 걸어 하나가 실패해도 나머지 파생은 계속한다.
2. **직접 관측 우선** — `_has_direct`가 (지표, 국가, 빈도)에 `source != derived`인 관측이 있다고
   판정하면 그 자리는 파생하지 않는다(OECD가 직접 주는 `cpi_yoy` 등).
3. **전년비** — `yoy`는 `DEFAULT_YOY_LAG`(W 52 · M 12 · Q 4 · Y 1) 시차의 **같은 빈도** 값과 비교한다.
   일별(`D`)은 전년비를 만들지 않는다. `partial_period` 플래그는 승계한다.
4. **통화가치 지수** — `fx_value_index_yearly`는 `fx[t−12] / fx[t] × 100`(100 = 1년 전과 같음,
   값이 크면 통화 강세). 월별에서만 만들고 Q/Y는 저빈도 집계가 담당한다. 증분 실행의 조회 창은
   `FX_VALUE_LAG_MONTHS=12`만큼 앞으로 늘린다.
5. **저빈도 집계** (`_aggregate_low_freq`) — 이번 실행이 건드린 (지표, 국가)의 **영향 버킷부터**만 만든다.
   - 소스가 이번 실행에 직접 만든 빈도는 건드리지 않는다(`target in by_freq`면 skip).
   - `agg=last`는 target보다 고빈도 중 **가장 저빈도** 시계열에서(M→Q, Q→Y 기말값은 같으므로 1차 소스의
     월별을 존중), `agg=mean`/`sum`은 **가장 고빈도** 원천에서 직접 집계한다.
   - `to_lower_freq`는 달력상 끝나지 않은 마지막 버킷에 `partial_period`를 붙이고 method에 표기한다.
6. **버킷 가드** — 저장된 target 항목과 집계 결과의 `source`가 다르면 그 **같은 버킷(period)** 만 덮지 않는다.
   가장 최신 항목과 비교하는 구현은 `poll_of_polls`가 만든 이번 달 `derived` M 때문에 지난달 W→M 집계가
   **영구 스킵**되는 결함이 있었다(코드 리뷰 지적 반영). 여론조사(`native_freq="W"`) 원천은
   진행 중인 달을 집계에서 제외해 `poll_of_polls`의 가중 평균에 맡긴다.
7. **증분 축소** — `_incremental`(=`ctx.since` 유무)이면 파생·집계 대상을 이번 실행이 건드린
   (지표, 국가)로 좁히고(`_touched_isos`), 조회 창을 `since − 시차`(`_window_start`)로 좁힌다.

**엣지 케이스·특례**

- `to_lower_freq`는 복합값(`value is None`) 관측을 거부하고, 더 고빈도로의 집계 요청·알 수 없는 빈도를
  `ValueError`로 거부한다. 입력이 같은 (지표·국가·빈도)인지 `_require_homogeneous`가 확인한다.
- `index100`은 기준 기간에 값이 없으면 `_resolve_base`가 **가장 가까운 이전 관측**을 쓰고
  `_base_note`로 그 사실을 method에 남긴다.
- 집계 결과의 unit/source/series_id/vintage와 flags는 버킷의 **마지막(대표)** 관측을 승계한다 —
  폴백 표기가 최신 상태를 따라가게 하기 위함이다.

## 6. 저장소

**목적** DynamoDB 단일 테이블과 S3 레이아웃을 **코드 한 곳**(`store.py`)에 고정한다. 다른 모듈은
키 문자열을 만들지 않고 이 클래스의 메서드만 쓴다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `store.py:MacroStore.put_observations` · `_put_observation` | 조건부 put → 개정 이력 갱신 |
| `store.py:_same_observed_value` | "값이 안 바뀌었다" 판정 |
| `store.py:MacroStore.query_series` · `get_observation` · `_query_all` | 시계열·단건 조회(페이지네이션 포함) |
| `store.py:MacroStore.put_docs` · `list_docs` · `latest_doc` · `set_review` | 정성 문서 |
| `store.py:MacroStore.rebuild_latest` | `LATEST#<indicator>` 재생성 + 순위 |
| `store.py:MacroStore.rebuild_snapshot` · `get_snapshot` | 국가 프로필 |
| `store.py:MacroStore.put_meta_items` · `get_meta` · `get_meta_many` · `list_meta` · `get_countries` | 지표 사전 |
| `store.py:MacroStore.log_ingest` · `get_ingest_latest` · `list_ingest` · `_next_due` | 수집 로그·케이던스 |
| `store.py:MacroStore.get_config` · `set_config` · `add_llm_tokens` | LLM 예산 |
| `store.py:MacroStore.acquire_lock` · `release_lock` · `get_lock` · `lock_active` | 수집 락 |

| `store.py:obs_pk` · `latest_pk` · `snapshot_pk` · `doc_pk` · `ingest_pk` | 키 생성 |

**알고리즘·규칙**

1. **조건부 put → 개정 이력** (`_put_observation`)
   - `put_item(ConditionExpression=attribute_not_exists(pk))`로 **신규**를 먼저 시도한다(1회 호출).
   - 조건 실패(기존 항목 존재)면 `get_item`으로 읽어 `_same_observed_value`로 비교한다.
     같으면 `n_unchanged`(옵션에 따라 `retrieved_at`만 touch), 다르면 이전 값
     `{value, vintage, retrieved_at}`(복합값이면 `payload`까지)를 `revisions` 앞에 넣고
     **최대 10건**(`MAX_REVISIONS`)으로 자른 뒤 `update_item`한다.
   - `payload`가 사라진 경우 `REMOVE`로 속성을 지운다(예전 복합값 잔존 방지).
2. **LATEST 재생성** (`rebuild_latest`) — 국가별로 `freq_pref` 순서대로 `sk` 내림차순 `Limit 2` Query를
   던져 최신·직전 관측을 얻고 `change`·`change_pct`를 계산한다. 순위는 value 내림차순이고
   **동값은 같은 순위**, `n`은 순위 대상 수다. `rank=False`면(단위가 국가별로 다른 `lcu_bn` 등)
   `rank=None`·`n=0`으로 둔다 — 국가 간 절대값 비교가 무의미하기 때문이다.
   호출부(`collect.py:Collector._rebuild`)는 `ind.unit not in NO_RANK_UNITS`로 이 값을 넘긴다.
3. **SNAPSHOT** (`rebuild_snapshot`) — 지표별 LATEST를 GetItem으로 모으고 문서는
   `DEFAULT_DOC_TYPES` 5종의 최신 1건을 `_DOC_SUMMARY_FIELDS`만 추려 담는다(항목 크기 억제, 전문은 `s3_key` 참조).
4. **INGEST** (`log_ingest`) — 실행 1건을 `<run_ts>` 항목으로, 요약을 `LATEST` 항목으로 2번 쓴다.
   `cadence_days`가 있으면 `next_due`를 계산한다(3장 케이던스 규칙과 동일 지점).
5. **CONFIG·토큰** (`get_config`/`add_llm_tokens`) — 날짜가 바뀌면 사용량을 0으로 정규화한다.
   누적은 조건부 `SET`(날짜 리셋) → 실패 시 `ADD`(원자 증가) 순서로 처리해 **동시 실행에서도 값이 유실되지 않게** 한다.
6. **락** — 2장·3장 참조. `lock_active`는 만료 전 락만 돌려주며 API의 409 판정에 쓰인다.
7. **S3** — `save_raw`는 `macro/raw/<source>/<날짜>/<name>.json.gz`(gzip), `save_doc_text`는
   `macro/docs/<type>/<iso>/<date>_<id>.md`. 버킷·클라이언트가 없으면 `None`을 돌려주고 수집은 계속한다.

**엣지 케이스·특례**

- 항목 단위 실패 격리: `put_observations`·`put_docs`는 한 건 실패가 배치 전체를 죽이지 않는다.
- sk 범위 질의 상한은 `_SK_MAX`(`"￿"`) 센티넬을 붙여 완전·부분 기간 상한을 한 규칙으로 처리한다.
- 모든 반환값은 `undecimalize`를 거쳐 Decimal이 밖으로 나가지 않는다.
- `_now`는 생성자 주입 가능(테스트 결정성). `table`은 boto3 Table 또는 `fakeddb.FakeTable`.

## 7. 소스 모듈별 구현 노트

공통 계약(CONTRACT 7장): 모듈은 `SOURCE_NAME`·`CADENCE`·`collect(countries, indicators, ctx)`를 노출하고,
정성 소스는 `collect_docs(countries, ctx)`를 추가로 노출한다. 네트워크·원본 저장·오류 기록은 전부
`sources/base.py:CollectContext`를 거치며, 국가 단위 실패는 `ctx.record_error`로 기록만 하고 계속한다.
각 모듈의 실측 기록(정확한 URL·차원·커버리지 숫자)은 **모듈 상단 주석**에 있다.

**`sources/bis.py`** — BIS Data Portal SDMX v2. `_collect_policy_rate`(`WS_CBPOL` `D.{bis}`),
`_collect_fx_usd`(`WS_XRU` `{FREQ}.{REF_AREA}.{CURRENCY}.{COLLECTION}`), `_collect_house_price`
(`WS_SPP` `Q.{bis}.N.628`). 국가를 `+`로 묶어 지표당 1회 호출한다. 3번째 차원은 USD가 아니라
**해당국 통화**이고 `COLLECTION=E`(기말)를 쓴다. `_start_period`가 빈도별 룩백(일 7 · 월 3 · 분기 4)을
적용하고, `_is_no_results`가 **HTTP 404 = 데이터 없음**을 오류가 아닌 정상으로 처리한다.
`_PERIOD_RE`에 어긋나는 `TIME_PERIOD` 행은 `record_error` 후 건너뛴다(잘못된 기간이 sk에 들어가면 정렬·집계가 깨진다).
정책금리 월별은 `last_per_group`으로 월 마지막 일별 관측을 취한다.

**`sources/oecd.py`** — OECD SDMX. 물가 데이터플로 **3개**(`DF_G20_PRICES` → `DF_PRICES_C2018_ALL` →
`DF_PRICES_ALL`)와 PPI용 `DF_KEI`를 쓴다. `_Batch`/`_Candidate` 데이터클래스로 국가 묶음 요청과 후보
시계열을 관리하고, `_pick_and_build`가 **국가별로 데이터플로 하나를 고정**한다(최신 기간 → `METHODOLOGY N`
우선 → 선언 우선순위). 기준연도가 다른 지수를 이어 붙이지 않기 위한 규칙이다. 속도 제한 대응:
요청 사이 1초 대기, 429는 30초 후 **1회** 재시도(`_fetch`). PPI는 원천이 2023-02에서 멈춰 있어
경고 로그(`PPI_FROZEN_UNTIL`)를 남긴다.

**`sources/worldbank.py`** — Indicators API. 국가를 `;`로 묶어 지표당 1회(+페이지네이션 `MAX_PAGES=10`).
유로존 ISO3는 `EMU`이고 응답의 `country.id`는 `"XC"`이므로 매칭은 반드시 **`countryiso3code`** 로 한다.
응답 상위의 `lastupdated`를 `vintage`로 쓰고, `value`가 null인 해는 건너뛴다. 연간 지표의 발표 지연·개정을
흡수하려고 증분 룩백을 **5년**(`LOOKBACK_YEARS`) 잡는다. 지표→코드 매핑은 registry 우선,
없으면 `DEFAULT_CODES`.

**`sources/imf.py`** — IMF 신 포털 SDMX 3.0(MFS `MFS_MA`). 차원 순서
`COUNTRY.INDICATOR.UNIT.FREQUENCY`이고 **와일드카드를 쓸 수 없다**(빈 칸을 두면 200 + 0행) —
`series_key`가 4개 차원을 모두 채우고 국가는 `+` 합집합으로 묶는다. `startPeriod`는 무시되므로
기간 필터는 **`c[TIME_PERIOD]=ge:YYYY-MM`** 를 쓴다(`data_url`). `normalize_period`가 `2025-M10` →
`2025-10`으로 바꾼다. `SCALE`은 표시용 힌트라 곱하지 않고, 단위는 `lcu_bn`으로 저장한다.
`_yoy_obs`가 12개월 전 값으로 `m2_yoy`를 만들고, `_warn_if_stale`이 정지 국가(CA·RU)에 경고를 남긴다.

**`sources/fred.py`** — 미국 전용 폴백. `_series_spec`이 지표→(시리즈 ID, freq, unit, method)를 정하고
`parse_observations`가 `"."`(결측)을 흘려보내며 `realtime_start`를 `vintage`로 쓴다
(`_clean_vintage`가 센티넬 날짜를 거른다). `FRED_API_KEY`가 없으면 **경고 한 줄 후 빈 리스트**이며
`fallback_source` 플래그는 붙이지 않는다(우선순위 판단은 수집기의 몫).

**`sources/yahoo_fx.py`** — 비공식 chart API(`v8/finance/chart/{symbol}`). UA가 없으면 429이므로
`ctx.http` 세션 UA가 필수다. `parse_chart`는 날짜를
`utcfromtimestamp(ts + gmtoffset).date()`로 복원하고(거래소 로컬 자정), 같은 날짜가 중복되면
마지막 값으로 덮는다(장중 시세). `_symbol_spec`의 `invert`로 `{CCY}USD=X` 계열을 역수 처리하고
`DX-Y.NYB`는 `dxy`(iso `US`)로 저장한다. **freq D만** 만든다 — 월별은 BIS가 1차 소스이고
폴백 집계는 수집기가 한다. chart API 차단 시 `_yfinance_fallback`.

**`sources/ember.py`** — 발전 믹스(복합값). **4단 경로**를 `_collect_resolution`이 해상도(연간/월간)마다 순서대로 탄다: ① API(`_collect_api`, 키 필요) ② **API 응답에 없는 국가만** 공개 CSV로 보충(`_csv_supplement`) ③ 키가 없거나 API가 실패하면 공개 CSV 전체(`_collect_public_csv`) ④ `owid.elec_mix_from_owid`(`_owid_fallback`). ②~④ 관측치에는 `fallback_source` 플래그가 붙는다. 인증은 **쿼리 파라미터 `api_key`가 먼저**이고(헤더 `X-API-Key`만 보내면 키가 유효해도 403), 거부를 만나면 다른 방식으로 1회 넘어간 뒤 통한 방식을 `ctx.extra[AUTH_EXTRA_KEY]`에 기억해 재시도 낭비를 없앤다(`_api_get`). 유로존은 `entity_code` 옵션(3자 ISO)에 없고 집계 엔티티 `entity=EU`로만 오며 두 파라미터를 한 요청에 섞으면 0행이 오므로 `_api_entities`가 요청을 **나눈다**. `label_for`가 전원 코드를 한글 라벨로 바꾸고 `EXCLUDED_SERIES`의 **"Net imports"는 발전이 아니라 제외**한다. `build_payload`가 `{items, total_twh}`를 만들고 `_normalize_period`·`_in_window`가 기간을 정규화·필터한다. 16~28MB CSV라 `DOWNLOAD_TIMEOUT=180`이며, API가 다른 해상도를 준 국가는 CSV 보충에서 제외한다(Ember에 월간 시계열이 없는 국가 때문에 월간 CSV를 헛되게 받지 않기 위함).

**`sources/owid.py`** — OWID 에너지 CSV(약 16MB)를 **배치당 1회** 내려받아
`ctx.extra`에 캐시하고(`load_dataframe`) 연료별 의존도를 만든다. `fuel_dependency`는
`max(0, 1 − 생산/소비) × 100`이며, **소비가 있고 생산이 결측이면 생산 0으로 본다**
(`ASSUME_MISSING_PRODUCTION_ZERO`, 한국·일본의 원유·가스) — 그 가정을 method에 적고 항상 `estimated` 플래그를 붙인다.
`elec_mix_from_owid`는 `biofuel_share_elec`가 `other_renewables_share_elec`에 포함돼 있어 **이중계상을 피해 제외**한다.
`energy_import_dep`는 이 CSV에 `primary_energy_production` 열이 없어 만들지 않고 로그만 남긴다(World Bank가 담당).

**`sources/wits.py`** — 수출 품목 구성(복합값). 국가당 요청 1건
(`reporter/{iso3}/year/{year}/partner/wld/product/all/indicator/XPRT-TRD-VL`),
`parse_exports`가 SDMX 2.1 XML을 읽고 `build_payload`가 상위 `TOP_N` 비중을 계산한다.
`OBS_VALUE` 단위는 **US$ 천**이라 1000으로 나눠 백만 달러로 저장한다. product 차원은 HS 챕터 97개가 아니라
**챕터 구간 16개**(`84-85` 등)이므로 payload의 `hs2`는 구간 문자열이며, 구간이 한 챕터면
`hs2_label_ko()`의 한글명을 쓴다(`sector_labels`). `_candidate_years`가 최신 연도부터 거슬러 시도하고
찾은 연도를 국가 간에 재사용한다.

**`sources/companies.py`** — 시총 상위 기업(복합값, 분기). 두 경로: ① 한·일·미·중은 기존 종목 카탈로그
재사용(`_from_catalog`, 주입점 `ctx.extra["catalog_loader"]`) ② 나머지는 `INDEX_TICKERS`를
yfinance로 조회(`_from_yfinance` → `_yf_snapshot`). `normalize_currency`가 런던 `GBp`·요하네스버그 `ZAc`
같은 **보조통화를 ÷100** 하고(`MINOR_UNIT_CURRENCIES`), `to_usd_bn`이 `ctx.extra["fx_rates"]`로 USD 환산한다.
관측치의 `source` 필드는 경로에 따라 `catalog` 또는 `yahoo`이고 모듈·INGEST 식별자는 `companies`다.
러시아는 Yahoo가 MOEX를 주지 않아 빈 결과 + 로그, 유로존은 단일 거래소가 없어 건너뛴다.

**관련 테스트** `tests/test_macro_sources_a.py`(base·bis·worldbank·yahoo·fred 53건)와
`tests/test_macro_sources_b.py`(oecd·imf·ember·owid·wits·companies 55건). 대표 항목:
`test_bis_...` 계열의 `TestBis::test_404_no_results_is_not_an_error`·`::test_since_uses_frequency_lookback`,
`TestWorldBank::test_url_joins_iso3_with_semicolon_and_uses_emu`,

`test_imf_wildcard_free_key_and_euro_member_skipped`, `test_ember_without_api_key_uses_public_csv`,

**알고리즘·규칙**

1. **구조화 출력 강제** — `invoke_json`은 Converse API의 `toolConfig`에 JSON 스키마를 넣고
   `toolChoice`로 그 도구 호출을 **강제**한 뒤 `_extract_tool_input`으로 `toolUse.input` 딕셔너리를 돌려준다.
   자유 텍스트를 파싱하지 않으므로 "JSON 파싱 실패" 경로가 없다. `validate_against_schema`가
   required 키·기본 타입만 자체 검증한다(의미 검증은 각 소스 모듈).
2. **예산** — 호출 전 `budget_check(예상 토큰)`이 False면 `BudgetExceeded`를 던져 정성 수집만 멈춘다.
   `collect.py:Collector._prepare_llm`이 `budget_check`를 `CONFIG#MACRO`의 오늘 사용량 + 예상치 ≤ 예산으로,
   `on_tokens`를 `store.add_llm_tokens`로 연결한다. 모델 기본값은 env `MACRO_LLM_MODEL` →
   `DEFAULT_MODEL_ID`(Haiku 4.5), 리전 us-east-1, 읽기 타임아웃 300초.
3. **재시도** — `ThrottlingException`만 지수 백오프로 최대 `MAX_THROTTLE_RETRIES=3`회 재시도하고
   그 외 오류는 재시도하지 않는다.
4. **인용 검증** — `keep_valid_quotes`가 `textutil.quote_in_text`(공백·따옴표·대시 정규화 후 부분 문자열 일치)로
   **원문에 실제 있는 인용만** 남긴다. 남은 인용이 0개면 문서를 **폐기**한다
   (`schema.Doc`이 AI 문서에 인용 1개 이상을 요구하는 것과 같은 방향의 이중 방어).
5. **결정문 링크 선별** (`pick_statement_links`) — 국가별 키워드(`_LINK_RULES` + `sources.yaml`의
   `link_keywords`)로 후보를 고르고 **그 안에서 URL/앵커의 날짜가 가장 최신**인 것을 쓴다
   (목록 순서만 믿으면 연준처럼 연초 성명이 먼저 나오는 페이지에서 오래된 문서를 집는다).
   목록 페이지 자신·PDF·HWP 첨부는 제외하고, 규칙이 하나도 맞지 않으면 일반 키워드 → 날짜 포함 링크로
   **fail-open** 완화한다. strict 모드는 무관한 페이지를 거부한다. 목록이 RSS/Atom이면 `links_from_feed`.
   UA는 `headers_for`가 `sources.yaml`의 `user_agent: browser` 여부로 고른다(일부 기관이 봇 UA를 WAF로 차단).
6. **여론조사 파서** — 1차는 **규칙 기반**(비용 0·재현 가능), LLM은 규칙이 0건을 낸 표에만 보조로 쓴다
   (`_llm_table`). 실측으로 해결한 6가지 문제: ① 좌석 예측·지역·가정 시나리오 표 제외
   (`heading_blocked` + 연도 절 제목 우선 `select_poll_tables`) ② 병합 헤더(rowspan/colspan) 전개
   (`textutil.extract_tables`) ③ colspan 중복 셀 이중계상 방지 ④ 연합 합계·"기타" 열 제외
   (`classify_columns` + `exclude_columns`) ⑤ 날짜에 연도가 없는 표("8–10 Sep")를 절 제목 연도로 보정
   ⑥ 정당 헤더 별칭 매칭(`build_alias_map`/`match_alias`, 그룹 접두 토큰까지).
   검증(`validate_poll`): 값 0~100 · 합계 ≤ 105 · `fieldwork_end` 유효·미래 아님·`MAX_AGE_DAYS=400` 이내.
   하나라도 실패하면 **그 조사만** 버린다.
7. **에너지 정책 변경 감지** — `collect_docs`가 URL들의 평문을 이어붙여 sha1을 만들고
   `ctx.extra["seen_hashes"]`에 있으면 **LLM을 호출하지 않는다**. 문서를 만들면
   `ctx.extra["energy_hashes"][iso] = sha1`을 남기고 수집기가 `INGEST#energy_policy/LATEST.hashes`에
   저장해 다음 실행의 `seen_hashes`로 복원한다. payload에도 `content_sha1`을 넣는다.
   원문 평문은 `ctx.extra["doc_texts"]`에 남겨 수집기가 `store.save_doc_text`로 S3에 보존한다
   (상한 `DOC_TEXT_MAX_CHARS=12,000`, 절단 표기 부착).
8. **주간 브리프 evidence 치환** — `build_brief`는 LLM이 낸 evidence 중 **입력으로 준 `doc_key`/`url`과
   일치하는 것만** 남기고(`_doc_index`), `quotes`는 LLM이 아니라 근거 문서의 `summary_ko` 첫 문장에서
   코드가 만든다(`_quotes_from_docs`, `_first_sentence`). 불릿이 `MIN_BULLETS`(5) 미만이면 거부한다.

**엣지 케이스·특례**

- 유로 회원국은 `sources.yaml`에서 `refer: EU`이므로 `cb_stance` 문서를 만들지 않고 EU 문서를 참조한다.
- `ctx.no_llm`이거나 `ctx.llm`이 없으면 정성 소스는 **원문만 S3에 저장**하고 문서를 만들지 않는다.

  `ai_generated=False`·`review_status="approved"`로 저장한다.

  `is_blocked_scheme`으로 `javascript:`·`data:` 계열을 버린다.

## 9. Lambda API

**목적** 프론트가 쓰는 8개 GET + 관리자 2개 POST를 **boto3만으로** 제공한다. Lambda zip에는
`api_handler.py`와 `macro_api.py`만 담기므로 `webui/macro/*`(PyYAML 필요)를 임포트하지 않고
계약 상수를 이 파일에 다시 선언한다.

**핵심 함수·클래스**

| 심볼 | 역할 |
|---|---|
| `backend/macro_api.py:MacroApi.handle` · `handle_admin` | 라우팅(정규식 없는 경로 분해) |
| `MacroApi._meta` · `_overview` · `_country_profile` · `_profile_parts` | 사전·히트맵·프로필 |
| `MacroApi._series` · `_observations` · `_related_docs` · `_docs` | 시계열·관측치 상세·문서 목록 |
| `MacroApi._politics` · `_party_series` · `_months_ago` | 정치 뷰 |
| `MacroApi._fx` · `_default_fx_base` | 통화가치 뷰 |
| `MacroApi._refresh` · `_active_lock` · `_review` | 관리자 경로 |
| `MacroApi._batch_get` · `_batch_get_via_client` · `_query_all` · `_get` | DynamoDB 접근 |
| `MacroApi._indicator_metas` · `_countries` · `_ingest_status` · `_fresh` | 5분 컨테이너 캐시 |

| `macro_api.py:is_euro_shared` · `_with_euro_flag` · `_plain` · `_cell` · `_median` | 유로 복제·Decimal 제거·셀 구성 |

**알고리즘·규칙**

1. **입력 검증** — 지표는 `INDICATOR_IDS` 화이트리스트, 소스는 `SOURCE_NAMES`, 문서 타입은 `DOC_TYPES`,
   freq는 `FREQS`, transform은 `TRANSFORMS`, 국가 코드는 `_ISO_RE`·최대 `MAX_COUNTRIES=20`개,
   period는 freq별 정규식(`_valid_period`). 실패는 400 + 한국어 메시지.
2. **기간 상한은 항상 강제** — `from`을 생략하면 `(to 또는 현재) − _max_years(freq)`를 넣는다.
   `MAX_YEARS=30`, 일별은 `MAX_DAILY_YEARS=10`, 국가당 포인트는 `MAX_POINTS_PER_COUNTRY=4000`.
   `_check_span`이 초과를 400으로 막는다. `/fx`의 `base`도 같은 규칙을 따른다(`_default_fx_base`).
3. **변환 창 확장** — `transform=yoy`면 `_shift_period`로 lag 기간 앞까지, `index100`이면 기준 기간이
   `from`보다 이르면 그 기간까지 조회 창을 넓히고, 변환 후 `from` 이전 포인트를 잘라낸다.
   `index100`은 기준값이 없을 때 실제 사용된 기간을 `base_used`로 돌려준다.
4. **유로 참조** — `is_euro_shared(indicator)`이고 대상이 유로 회원국이면 `EURO_REF="EU"` 값을 읽어
   복제하고 `_with_euro_flag`가 `euro_area_shared` 플래그를 붙인다. 응답에는 복제된 국가 목록(`euro_shared`)을 함께 준다.
5. **BatchGet** — `/meta`의 지표 사전 38건은 pk가 지표마다 달라 Query로 한 번에 읽을 수 없으므로
   `BatchGetItem`을 25건 단위로 던지고 `UnprocessedKeys`를 재시도한다. 실패 시 `get_item` 반복으로 폴백한다.
   모든 Query는 `_query_all`이 `LastEvaluatedKey`를 따라간다(Scan 금지, GSI 없음).
6. **캐시** — 국가·지표 사전과 수집 로그는 Lambda 컨테이너에 `META_CACHE_TTL=300`초 캐시한다
   (요청마다 38+14 Get을 막는다).
7. **관리자 refresh** — 워커 태스크 정의를 공용으로 쓰고 `command`만 교체한다
   (`python webui/macro/collect.py --sources … [--force] [--countries …]`). 진행 중 수집이 있으면
   (`_active_lock`) **409**로 거부한다. RunTask 실패는 상세를 로그에만 남기고 고정 문구로 500을 답한다.
8. **관리자 review** — `ConditionExpression=attribute_exists(pk)`로 없는 문서를 404로 구분하고
   `review_status`·`reviewed_by`·`reviewed_at`(+`review_note` 1,000자)만 갱신한다.
9. **응답 규약** — 성공 `{"ok": true, …}` / 실패 `{"error": "한국어 메시지"}`. 모든 Decimal은
   `_plain`으로 float/int로 바꿔 내려준다.

**엣지 케이스·특례**

- 테이블 미배포(환경변수 없음) 시 `/api/macro/*`는 503을 돌려준다.
- 국가 프로필은 SNAPSHOT GetItem 1회가 기본이고, 없으면 LATEST 폴백으로 조립한다(`_profile_parts`) —
  응답의 `profile_source`가 어느 경로인지 알려준다.
- 개요 히트맵은 지표당 LATEST Query 1회 + 중앙값(`_median`)이며, 지표 목록은 화이트리스트로 제한된다.
- 정치 뷰의 정당별 월 시계열은 `_party_series`가 `party_support` 관측을 정당별로 재배열해 만든다.

**알고리즘·규칙**

1. **마운트·라우팅** — `app.js`가 `mount(rootEl, { apiFetch, elem, isAdmin })`를 1회 호출하고
   해시가 바뀔 때마다 `route(location.hash)`를 부른다. 이 파일은 `#view-macro` 안쪽만 만진다.
   라우트 5개(`overview`·`country`·`indicator`·`fx`·`politics`)는 `parseRoute`가 해석한다.
2. **캐시·흐림 유지** — `get(path)`가 응답을 `CACHE_TTL`(5분) 메모리 캐시에 넣고, 필터 변경 시
   `loadInto`가 **이전 차트를 흐리게 유지한 채** 새 데이터를 기다린다(빈 화면 깜빡임 방지).
3. **차트 프리미티브** — 시계열 점은 `{period, value}`이고 x축은 모든 시리즈 기간의 **합집합**
   (`unionPeriods`)이다. 값이 없으면 선을 끊고 표·툴팁에는 '—'로 쓴다. 국가 색은 `countryColor`로
   8슬롯 고정이라 필터로 국가가 빠져도 색이 바뀌지 않는다. 툴팁은 문서 전체에서 단일 DOM(`#macro-tooltip`)을 쓴다.
4. **히트맵 발산색** — 열별로 **중앙값과 MAD**를 구해 z(MAD 배수)를 만들고 `heatColor(z)`가
   임계값(0.35 / 0.9 / 1.6)으로 3단 발산색을 고른다. 이상치 하나가 색 스케일을 삼키지 않게 하려고
   표준편차 대신 MAD를 쓴다. 배경 밝기에 따라 글자색을 어둡게 바꾼다.
5. **지연 점 표시** — `staleNote(col, cell)`가 `asof`(빈도별 최신 기간)와 셀의 기간을
   `periodIndex`로 비교해 `STALE_GAP` 이상 벌어지면 `'2026-02 (지연)'`을 붙인다.
   연간 지표는 열 메타의 `annual` 판정으로 Y 기준으로 본다.
6. **드로어** — 관측치 상세는 쿼리 `?obs=<indicator>,<iso>,<freq>,<period>`로 열고 닫을 때
   `history.replaceState`를 쓴다(`replaceHash`) — `hashchange`가 발생하지 않아 뷰 재렌더가 일어나지 않는다.
7. **링크 화이트리스트** — `SAFE_URL_RE`(http(s)·프로토콜 상대 `//`·같은 출처 경로)만 `<a href>`로 만들고
   그 외 스킴은 텍스트로만 표시한다(`safeUrl`/`extLink`). API 문자열은 항상 `textContent`로 넣고
   `innerHTML`을 쓰지 않는다.
8. **CSV 접두 방어** — `csvCell`이 `=`·`+`·`-`·`@`로 시작하는 값에 접두를 붙여 스프레드시트 수식 실행을 막는다.
9. **검토 버튼** — `deps.isAdmin()`이 참이고 문서가 `pending`이면 카드에 [승인]/[반려]를 붙인다
   (`reviewButtons` → `POST /api/admin/macro/review`, 본문 SHA-256 헤더는 공용 `apiFetch`가 처리).

**엣지 케이스·특례**

- `/meta` 조회가 실패해도 `FALLBACK_COUNTRIES`(CONTRACT 1장 국가 20개)로 최소 동작한다.
- 복합값 지표(`PAYLOAD_INDICATORS`)는 지표 비교 select에서 제외한다(단일 값 시계열이 아니므로).
- 경쟁 정당이 없는 체제(`NO_PARTY`: CN·SA)와 정부 지지율 대상이 아닌 EU(`NO_GOV`)는 빈 칸 대신 안내 문구를 쓴다.
- 지표가 요청 빈도를 저장하지 않으면 `effFreq`가 저장 빈도로 낮추고 `freqNote`로 그 사실을 알린다.

**관련 테스트** JS 단위 테스트는 없다. 대신 ① `node --check`로 문법 검증 ②
`webui/mockups/macro-dev-harness.html`로 합성 응답을 주입해 검토 버튼·실패 배지 확인
③ `devserver.py` + 헤드리스 Chrome으로 실데이터 스크린샷(`webui/mockups/screenshots/live-*.png`) 검수.
프론트가 의존하는 응답 규칙은 서버 쪽 테스트(`tests/test_macro_api.py`)가 지킨다(CONTRACT 9.1절).

**알려진 한계** 모바일(≤900px) 레이아웃은 검수하지 않았다(히트맵 20행 × 9열·드로어). 자동화된 JS
단위 테스트가 없어 렌더 로직 회귀는 스크린샷 검수에 의존한다.

## 11. 인프라

**목적** 새 스택·새 이미지·새 파이프라인을 만들지 않고 기존 CloudFormation 스택
(`tradingagents-webui`)에 리소스만 더한다.

**핵심 위치**

| 위치 | 내용 |
|---|---|
| `../infra/template.yaml` `MacroTable` | DynamoDB 단일 테이블(pk/sk, 온디맨드, PITR, `DeletionPolicy: Retain`·`UpdateReplacePolicy: Retain`) |
| `../infra/template.yaml` `MacroScheduleRule` | EventBridge `cron(0 21 * * ? *)`(= 매일 06:00 KST), `State: !Ref MacroScheduleEnabled` |
| `../infra/template.yaml` 파라미터 5개 | `FredApiKey`·`EmberApiKey`(`NoEcho`), `MacroLlmModel`, `MacroLlmDailyTokenBudget`, `MacroScheduleEnabled` |
| `../infra/template.yaml` 출력 | `MacroTableName` |
| `../infra/deploy.sh` 0단계 | 루트 `.env`에서 **필요한 4개 변수만** 골라 읽기 |
| `../infra/deploy.sh` Lambda zip | `api_handler.py` + `macro_api.py`(없으면 경고 후 기존 방식) |

**알고리즘·규칙**

1. **스케줄은 하루 1회 기동만** — EventBridge는 21:00 UTC에 워커 태스크를 `command` 오버라이드
   (`{"containerOverrides":[{"name":"worker","command":["python","webui/macro/collect.py"]}]}`)로 띄우고,
   소스별 실제 주기는 `collect.py`가 `INGEST#<source>.next_due`로 판단한다. 아침 6시인 이유는
   미국 장 마감·유럽 발표가 끝나 하루치 데이터가 완결되는 시각이기 때문이다.
2. **실행 역할 재사용** — `MacroScheduleRule`의 `RoleArn`은 카탈로그 스케줄의 `CatalogScheduleRole`을
   그대로 쓴다. EventBridge의 ECS 실행 권한은 **태스크 정의 단위**라 `command`만 달라도 유효하다.
3. **IAM 최소 권한** — 워커 역할에는 매크로 테이블 쓰기와 `macro/*` S3 권한만, API 역할에는
   `GetItem`·`BatchGetItem`·`Query`·`UpdateItem`(검토·예산 조정)만 준다. **`PutItem`은 주지 않는다**
   (수집 쓰기는 워커의 몫, 수집 락 확인은 GetItem으로 충분). S3는 `macro/docs/*` 읽기만 허용하고
   `macro/raw/*`(원본)는 API에 노출하지 않는다. 코드 리뷰에서 **미사용 액션을 제거**했다.
4. **테이블 보호** — 30년 치를 수 시간에 걸쳐 외부 API로 모은 데이터라 스택에서 테이블이 제거·교체되어도
   남기도록 `Retain`이고, 수집 버그로 값을 덮어써도 되돌릴 수 있게 PITR을 켰다.
5. **배포 스크립트** — `.env` 전체를 `source`하지 않고 4개 변수만 골라 읽는다(이 스택과 무관한 키가 많다).
   이미 셸 환경에 있는 값이 우선이라 `FRED_API_KEY=... deploy.sh` 형태의 1회성 오버라이드가 가능하다.

**엣지 케이스·특례**

- **`NoEcho`의 한계** — 콘솔·스택 이벤트에는 값이 노출되지 않지만 **ECS 태스크 정의의 환경변수로는 보인다**.
  키를 주지 않고 재배포하면 스택에 저장된 기존 키가 빈 값으로 덮어써져 해당 소스만 스킵된다
  (그래서 키는 `.env`에 두는 것을 권장하고, 이 한계를 문서화했다). SSM SecureString 이전은 후속 과제다.
- `MacroScheduleEnabled`로 스택 변경 없이 자동 실행을 끌 수 있다(개발 중 수동 RunTask만 쓰거나 비용을 즉시 멈출 때).
- 워커 이미지에는 `pyyaml>=6`을 명시했다(레지스트리 로드).

**관련 테스트** `aws cloudformation validate-template`(파라미터 15개 확인) + `deploy.sh` 실행 로그.
인프라 자체의 단위 테스트는 없다.

**알려진 한계** 키가 태스크 정의에 평문으로 남는다(위 `NoEcho` 항목). 스케줄이 1개뿐이라
"일별 소스만 자주, 월별 소스는 드물게" 같은 분리 기동은 못 하고 `next_due` 판정에 의존한다.

## 12. 테스트 전략

**목적** 네트워크·AWS·비용 없이 **실제 응답 형식**과 **실제 호출 규약**을 검증한다. 매크로 테스트
409건(8파일 6,138줄)이 모두 오프라인이다.

**핵심 위치**

| 위치 | 역할 |
|---|---|
| `fakeddb.py:FakeTable` · `FakeS3` | 인메모리 DynamoDB/S3 페이크 (테스트·dry-run·devserver 공용) |
| `fakeddb.py:_reject_floats` · `_client_error` | float 거부·`ClientError` 재현 |
| `tests/fixtures/macro/` | 실제 API 응답 축소본 19개(+`llm/`) |
| `../../scripts/macro_smoke.py` | 소스별 **라이브** 스모크(실제 공개 API 호출) |
| `devserver.py` | 덤프 위에서 실제 `api_handler.py` + 프론트 구동 |

**알고리즘·규칙**

1. **페이크는 시그니처·반환 형태를 그대로 흉내 낸다** — `get_item` → `{"Item": …}` 또는 `{}`,
   `query` → `{"Items", "Count", "LastEvaluatedKey"?}`. 호출부를 페이크용으로 분기하지 않는다.
2. **실패도 흉내 낸다** — 조건부 쓰기 실패는 `ClientError(ConditionalCheckFailedException)`,
   **float 저장은 `TypeError`**(DynamoDB와 동일). Decimal 누락 버그를 테스트에서 잡는다.
   지원하지 않는 표현식은 조용히 무시하지 않고 `NotImplementedError`로 알린다.
3. **성능** — `query`는 pk별 sk 인덱스(쓰기 시 `bisect` 유지)로 후보를 좁힌다. 전 항목 정렬을 없애
   55k 항목·4.5k 쿼리가 **221초 → 4초 미만**으로 줄었다(3차 웨이브 후속).
4. **픽스처는 실제 응답을 줄인 것** — BIS CSV 3종·OECD CSV 4종·IMF CSV·World Bank JSON·WITS XML·
   Yahoo JSON 3종·Ember(CSV·JSON)·OWID CSV·FRED JSON·카탈로그 JSON. 형식이 바뀌면 테스트가 먼저 깨진다.
5. **라이브 확인은 분리** — 유닛 테스트는 네트워크를 쓰지 않으므로 "지금 API가 살아 있는지"는
   `scripts/macro_smoke.py --source <name>`으로 확인한다(항상 `dry_run=True`, `--save-raw` 없으면 원본도 남기지 않음).
6. **화면 검증** — `devserver.py`가 `api_handler.py`를 파일 경로에서 importlib로 로드하면서
   `boto3.resource/client`를 가로채(dynamodb → FakeTable, s3 → FakeS3, ecs → 가짜 RunTask) AWS 호출을 차단하고,
   `check_auth`/`check_admin`을 통과 람다로 바꾼다. 여기에 헤드리스 Chrome을 붙여 5개 화면 스크린샷을 남긴다.

**엣지 케이스·특례**

- `FakeTable(page_size=2)`로 페이지네이션 경로를 테스트한다.
- `tests/test_macro_collect.py`는 `collect.SOURCE_MODULES`를 가짜 모듈로 monkeypatch해 네트워크 없이
  병합·파생·케이던스·락 로직만 검증한다.
- `MACRO_DEV_NOAUTH`는 devserver가 자기 환경에만 세팅하는 표식이며 운영 코드는 devserver를 참조하지 않는다.

**관련 테스트** `tests/test_macro_store.py::test_fake_table_condition_expression_forms`,
`::test_fake_table_update_expression_support`, `::test_fake_table_query_uses_partition_index`,
`::test_fake_table_query_and_batch_writer`, `::test_fake_s3_missing_key_and_listing`.

**알려진 한계** 페이크는 DynamoDB의 일부 표현식만 지원한다(`DELETE`는 `NotImplementedError`).
JS 단위 테스트가 없다. 라이브 스모크는 CI에 넣지 않았다(외부 API 의존).

## 13. 로컬 개발 절차

**목적** AWS 없이 수집 → 저장 → API → 화면까지 한 번에 확인한다.

```bash
# 1) 실 API에서 소량 수집 (AWS 쓰기 없음, 원본은 ./.macro_raw/)
python webui/macro/collect.py --dry-run --force --no-llm \
  --sources bis,yahoo --countries KR,US,EU --since 2026-01-01 \
  --dump /tmp/macro_dump.json

# 2) 덤프 위에서 실제 Lambda 핸들러 + 프론트 구동
python webui/macro/devserver.py --load /tmp/macro_dump.json --port 8765
#    → http://127.0.0.1:8765/dev-login  (가짜 토큰 4개를 넣고 #/macro 로 이동)

# 3) 소스 하나만 라이브로 확인 (관측치 수·국가별 최신값·오류 표)
python scripts/macro_smoke.py --source bis --countries KR,US,EU --since 2026-06-01

# 4) 테스트·린트
pytest tests/test_macro_*.py -q
ruff check webui/macro webui/backend
node --check webui/frontend/macro.js && node --check webui/frontend/charts.js
```

**규칙·주의**

1. `--dry-run`은 `FakeTable`/`FakeS3`를 쓰므로 **AWS에 쓰지 않는다**. `--dump`로 남긴 JSON 1개에
   테이블 항목과 S3 객체가 함께 들어간다(`dump_state`). 수집 락은 덤프에서 제외된다.
2. `--load`는 `load_state`로 그 덤프를 페이크에 복원한다. 같은 덤프를 여러 번 띄울 수 있다.
3. `--no-llm`이면 정성 소스는 원문만 저장하고 문서를 만들지 않는다 — Bedrock 비용 없이 정량 화면을 볼 수 있다.
4. 화면 스크린샷은 헤드리스 Chrome으로 `#/macro`, `#/macro/country/KR`, `#/macro/indicator/policy_rate`,
   `#/macro/fx`, `#/macro/politics/KR`을 순서대로 찍어 `webui/mockups/screenshots/live-*.png`에 남겼다.
5. 실데이터 없이 화면 요소(검토 버튼·실패 배지)만 보려면 `../mockups/macro-dev-harness.html`을 쓴다
   (실제 `macro.js`·`charts.js`를 합성 응답으로 구동).

**알려진 한계** devserver는 인증을 우회하므로 **로컬 전용**이다. dry-run은 실제 API를 호출하므로
`--countries`·`--since`로 범위를 좁히지 않으면 부트스트랩과 같은 시간이 걸린다.
